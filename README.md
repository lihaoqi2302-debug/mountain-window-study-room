# 山窗书屋 · 好友共学

普通访问直接进入单机。创建房间或打开邀请时才连接 Trystero。项目提供使用现有场景与书稿的正式书屋构建，以及可加载自定义 GLB 的示例构建。

## 正式书屋本地预览

使用 Node.js 22.12 或更新版本。在本项目目录运行以下命令。已有依赖时可以直接运行后两行。

```sh
npm ci
npm --prefix ../cozy-bookstore ci
npm run build:formal
npm run preview:formal
```

打开 `http://localhost:5196/`。桌面点击右上「共学」，触屏从「书屋工具 → 共学」进入。通过共学面板建房、加入房间或切换昵称和状态。正式场景保留 34 页《地球 Online》和原有的翻页、窗景、物件、自由行走与座位。茶几上另一本《本科生速通指南》打开试读抽屉。

`dist-formal/` 含正式场景和书稿，在本地单独构建。普通的 `npm run build` 生成示例版 `dist/`。两个版本使用各自的房间，邀请链接应从要测试的版本生成。

## GLB 与示例书屋本地启动

使用 Node.js 22.12 或更新版本。

```sh
npm ci
npm run dev
```

打开终端显示的 localhost 地址。`WASD` 或方向键控制角色，触屏设备可以长按方向按钮。点击桌上的书或右侧书名试读，按 `Esc` 合上。

```sh
npm run typecheck
npm run build
npm run preview
```

构建产物在 `dist/`，可以通过 HTTPS 静态站点提供。相对资源路径支持部署在网站子目录下。复制出的邀请链接沿用当前页面的访问地址，因此 localhost 链接只适合同一台电脑测试。

将采用米制、Y 轴向上的模型放在 `public/models/study_room.glb`。Draco 解码文件在启动和构建时复制到站点。模型缺失、损坏或加载失败时，默认房间仍可走动、入座、阅读和听雨或炉火。

| GLB 节点 | 用途 |
| --- | --- |
| `book_earth_online`、`book_undergrad_guide` | 点击节点上的网格或它的后代打开书。 |
| `seat_sofa`、`seat_desk` | 节点原点是座面位置，局部 +Z 是面朝方向。点击节点网格或其后代入座。 |
| `room_bounds`、`collision_*` | 可选的房间边界与家具碰撞网格。加载后隐藏这些辅助网格。 |
| `spawn_player`、`camera_overview`、`camera_target` | 可选的出生点、全景机位和注视点。 |
| `hearth_flame` | 可选的炉火模型组，由共学房间的壁炉状态控制。 |

## 共读与房间环境

- 房主在共学面板切换窗景、壁炉和环境音方案。房主离线时，在线成员保留最近同步的设置。房主在原浏览器返回时恢复控制。
- 听众点击「允许播放共学环境音」后，才在自己的浏览器听到同步的声音。每位成员独立控制是否播放和音量。
- 阅读时打开「章节便签」，先保存到本机，再按需分享至当前房间。只同步已分享的便签，每个房间交换最近 72 张。晚加入者从在线成员同步章节便签。所有人离线时，新浏览器只能等待在线成员重连。

## GitHub Pages 部署

将本目录的示例版代码推到目标仓库的 `main` 分支。仓库 Settings → Pages → Build and deployment 选择 GitHub Actions，再运行 `Deploy the study room example`。部署完成后在 Pages 地址创建邀请，验证子目录资源、跨网加入和退出回退。

工作流发布 `dist/`，其中是示例内容和本地 Draco 解码器。正式场景和书稿由 `build:formal` 输出到 `dist-formal/`，供本地使用。若选择自定义 GLB，再把允许公开分发的模型放到 `public/models/`。

本项目代码使用 [MIT 许可证](LICENSE)。Three.js 和 Google Draco 的许可证随解码器复制到发布产物。正式书屋及书稿各自保有原有的素材和使用约定。

## 联机验收

1. 用两个独立浏览器会话打开小样。在一端创建房间并复制链接，另一端打开链接。双方都应显示「房间里有 2 人」。
2. 移动任一角色，确认另一端的角色跟随位置和朝向。修改昵称或打开试读时，检查远端显示是否更新。
3. 刷新加入端，确认重连后双方各有两个角色。退出后，剩余成员回到「等待好友」，退出者仍可在自己的书屋走动和阅读。
4. 断开网络或阻断公共信令，确认页面显示失败原因并允许重试或返回单机。等待好友时可以继续使用单机操作。
5. 跨网验收使用两个网络均能访问的同一个 HTTPS 预览地址。分别在宽带与手机流量下重复以上步骤，再用目标校园网复测。若长期停在「等待好友」，分别检查公共信令可达性与 WebRTC 连接状态，确定是否需要 TURN。

## 项目结构

- `src/store/useStudyRoomStore.ts` 管理角色、成员和本地设置。
- `src/online/roomSession.ts` 管理邀请链接、公共信令、角色同步与退出清理。
- `src/scene/` 提供房间、角色绘制和移动控制。
- `src/data/books.json` 提供两本书的试读数据。
- `src/audio/ambience.ts` 在浏览器中生成本地雨声和炉火声。
